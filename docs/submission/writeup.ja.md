# 雪かき Yukikaki ― 札幌から広がる、AIネイティブなハッカソン

**Team Snowball・Hack Hokkaido Build Week（2026年11月・札幌）・カテゴリーB「少ない人手で、同じまちを」**
公開版：<https://project-yukikaki.vercel.app>・コード（MIT）：<https://github.com/amomusik/project-yukikaki>

> ハッカソン版の Peatix や Luma。準備は済ませて、資金も見つけておきます。
> *根回しは済んだ。仕込みもできた。*

## 課題

北海道のまちでは、人手が減っています。札幌の除雪会社やラーメン店、小樽の旅館、旭川近郊の農園。どこも電話予約や配車の連絡、補助金の書類に毎週何時間も取られています。学生や地元のエンジニアなら、その多くを AI で自動化できます。それでも実際にはなかなか進みません。ハッカソンの**前**にやるべき準備が、誰の手にも渡らないからです。必要なのは、実際の事業者からの明確な課題、使ってよいデータ、了承をもらうべき人への根回し、会場、資金、そしてデモの後も残ってくれるチームです。

北海道の冬には、誰かが先に雪をかいて道をあけます。必要なのに、誰もやりたがらない仕事。それが「雪かき」です。

## 気づき

足りないのは作り手ではなく、準備です。インタビュー、調査、データ、レビュー、マッチング、助成金の下調べといった手間を AI エージェントが引き受け、判断はすべて人が行います。そうすれば、委員会が必要だった仕事を、まちのホスト1人で回せます。それが**アイデアと試作品のためのテストキッチン**です。お店が本当の困りごとを持ち込み、チームが試作し、事業者がふだんの1週間で試します。最後に効果確認で、続けるか、作り直すか、やめるかを決めます。

## 作ったもの

Next.js 15 の日英対応 Web アプリで、Vercel の東京リージョン（`hnd1`）で動いています。すべてのページに `/ja` 版と `/en` 版があります。

1. **音声インタビューからブリーフへ**：事業者は ElevenLabs のエージェントと10分ほど話します（テキストのフォームも使えます）。会話から取り出した項目（困りごと、今のやり方、週に失っている時間、データの扱い）が、日英のブリーフの下書きになります。
2. **公的な情報源だけで裏付け**：Linkup で検索するのは `go.jp`・`lg.jp`・`or.jp`・`ac.jp` と、その市の公式サイトだけです。その市のデータが見つからなければ、降雪量・1月の気温・人口・高齢化率が近い**類似都市**（札幌なら旭川・青森・長野）を探し、それでもなければ全国統計にあたります。公的な情報源が何も見つからなければ、ブリーフに「裏付けなし」と表示します。
3. **合成の代替データ**：Adaption Labs が、裏付けとなった事実だけをもとに、架空の日本語データを作ります。作り手は事業者の個人データに一切触れません。裏付けのないブリーフにはデータを作らず、作ろうとするとコードがエラーで止めます。
4. **AI の事前レビューと人の判断**：Dify のワークフローが、プライバシー・実現性・裏付け・日英の表現を確認します。確認できた個人情報は取り除き、見つかった場合は推奨を必ず「要修正」にします。承認できるのはホストだけで、承認・却下は監査記録の残る1つの処理（`decide()`）を必ず通ります。
5. **課題グラフ**：Neo4j で、課題と事業者・まち・データセット・スキル・作り手・地元の関係者・会場・資金提供者をつなぎ、スキルの合う作り手を提案します。
6. **助成金の自動マッチング**：承認されると、デジタル庁の公式 API **jGrants** から募集中の制度を照合します（Linkup で補うこともできます）。締め切り・金額・補助率を表示し、要件の確認は Grantline に引き継ぎます。
7. **イベントと参加登録**：ハッカソン、デザインシャレット、テストキッチンを扱います。定員、キャンセル待ちからの自動繰り上げ、`.ics` 書き出し、共有リンクに対応しています。イベントページには、取り組む課題と、それに合う助成金の上位候補も表示します。
8. **チーム・納品・効果確認**：各チームのリーダーは必ず1人です（データベースで保証）。リーダーは事業者の窓口となり、納品後90日間はサポート担当を務めます。ホストは1回限り・14日間有効の効果確認リンクを送ります。事業者はフォームか音声（2つ目の ElevenLabs エージェント）で答え、`/admin` で**週あたりの削減時間**が集計されます。

## パートナーツールの実際の役割

| パートナー | アプリの中での役割 |
|---|---|
| **ElevenLabs** | 会話型 AI エージェント2つ（事業者インタビューと効果確認の音声レビュー）。署名付き URL と、HMAC で検証する通話後 Webhook。 |
| **Linkup** | 公的なドメインだけを対象にした段階的な裏付け検索（出典付き）。市町村の助成金の補足検索にも使います。 |
| **Adaption Labs** | `datasets/invent` で、裏付けに基づく日本語の合成データを作成。既存の `yukikaki:{業種}:{市}` データセットは再利用します。 |
| **Dify** | インポートできるワークフロー2つ（`dify/brief-review.yml`・`dify/team-review.yml`）。事前レビューと個人情報の除去。あくまで推奨です。 |
| **Neo4j** | 課題グラフと、スキルに基づく作り手の提案。データベースから作る写しなので、`pnpm graph:rebuild` でいつでも作り直せます。 |
| **Neon** | サーバーレス Postgres。すべての記録・判断・外部呼び出しの正本です。 |

ログインは Clerk、メール送信は Resend です。外部への呼び出しはすべて1つのガード（`withFallback`）を通り、タイムアウトをかけたうえで、呼び出しごとに `service_events` に1行記録します。

## 本物とデモの区別

- **本物**：パイプライン、パートナーへのすべての呼び出し、jGrants の照合、参加登録とキャンセル待ちの処理、ホストの判断と監査記録。本番では `REQUIRE_LIVE_SERVICES=true` にしているので、呼び出しが失敗するとホストに課題として表示されます。用意したデータで置き換えることはありません。
- **デモデータ**：シードした8事業者（札幌・旭川・小樽ほか5つのまち）と、そのチーム、効果確認の回答、イベント3件は架空のもので、画面に「デモ」バッジを表示しています。出典と代替データは、実際のパイプラインを動かして作りました（`pnpm prebake`）。
- **評価（evals）**：結果は `evals/results/2026-11-26-summary.md` にそのまま公開しています。20項目中16項目が合格、4項目が不合格です。不合格の中には助成金の関連度（0.375）と裏付けの精度（0.5）があり、改善を進めています。

## 助成金と法令（行政書士）

2026年1月から、報酬を得て補助金の申請書類を作成できるのは、行政書士の資格を持つ人に限られています。雪かきが行うのは制度を**探して照合する**ところまでです。助成金を表示するすべての画面と `/api/grants` の応答にこの注意書きを入れており、申請はホストが行政書士と一緒に行います。申請書の下書きは作りません。

## オープンで、どのまちでも使える

MIT ライセンスです。新しいまちで動かす手順は次のとおりです。`lib/grounding/city-profiles.ts` にまちの情報（降雪量・気温・人口・公式ドメイン）を1行追加し、足りない業種があれば加えます。`seed/seed.json` にまちの関係者・会場・資金提供者を登録したら、デプロイします。Dify のワークフローは DSL としてインポートでき、`pnpm setup:elevenlabs` で音声エージェント2つを作成、`pnpm check:services` で8つのサービスを確認できます。CI では unit・integration・contract のテスト、Playwright、axe によるアクセシビリティ検査を行います。

## これから（近日公開。まだ使えません）

- **どんなチームでも**：チームに足りない準備役（リサーチャー、スカウト、資金係、根回し役、翻訳係、データシェフ）を AI のお手伝い役が担います。トップページのプレビューはブラウザ内だけで動くものです。
- **AI プロダクトマネージャー**：進み具合を確認し、つまずきに気づき、締め切りを知らせます。提案するのは AI、決めるのは人です。
- **ポイントと特典**：開発、メンター、実際の効果に応じてもらえます。
- 助成金と裏付けの精度を上げ、北海道のまちのプロフィールを増やします。

この3つの機能は、トップページの共通ウェイトリストで受け付けています。

## チームとクレジット

札幌で **Team Snowball** が制作しました。パートナー：ElevenLabs、Linkup、Neo4j、Dify、Neon、Adaption Labs。ほかに Clerk、Resend、jGrants（デジタル庁）、Grantline を使っています。動画とスライドの素材は **PixVerse**（動画クリップ）、**Hyper3D Rodin**（3D モデル）、**Cascadeur**（キャラクターアニメーション）で作りました。8ビットのイラストは `public/images` にあります。
